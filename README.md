# Digital Lending and Loan Processing Platform

## Project Overview

The Digital Lending and Loan Processing Platform is a web-based application designed to simplify the loan processing workflow. It allows users to apply for loans, view loan details, track loan status, and manage repayment information through an online platform.

## Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Java
- Spring Boot
- REST API

### Database
- MySQL

### Version Control
- Git
- GitHub

## How to Run Locally

### Frontend

1. Open the project folder in VS Code.
2. Open the terminal.
3. Navigate to the frontend folder:

bash

npm.cmd run dev
